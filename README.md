## 📝 Описание / Description

### Български
Това графично декстоп приложение позволява:
- Въвеждане на ЕГН в текстово поле
- Автоматична проверка за валидност на ЕГН
- Декодиране на информация
- Опция за изчистване на всички полета

### English
This desktop application provides:
- Input field for EGN numbers
- Automatic EGN validation
- Decoding of personal information
- Clear-all functionality

### English
Installation file:

## 🚀 Употреба / Usage

### Български
- Въведете ЕГН в текстовото поле
- Натиснете бутон "декодирай" за резултати
- Използвайте бутон "изчисти" за нулиране

### English
- Enter EGN in the input field
- Click "decode" for results
- Use "clear" to reset
